# Ambiguous Requirements Q&A Registry

This directory stores clarification requests generated by agents when requirement ambiguity or conflicting rules are encountered.

## Purpose

To prevent guessing or hallucinating business rules:
1. When an agent faces an unresolved design decision, it creates `QA/QA-<task-id>.md`.
2. The agent halts work on the affected branch until the question is answered.
3. The human operator reads the question, selects an option or provides instructions, and updates the file.
4. The agent reads the resolved decision and continues implementation.
