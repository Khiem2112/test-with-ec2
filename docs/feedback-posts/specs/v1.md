## 1. Overview & Acceptance Criteria

- Objective: Cung cap cong cu tiep nhan y kien dong gop va bao loi tu cong dong nguoi dung; to chuc theo Board chuyen de, Category ky thuat va Tag linh hoat; tich hop co che goi y bai tuong dong tuc thi nham tranh phan manh phan hoi.
- Target Actors: End User (Voter/Customer), Product Manager, Moderator.
- Key Scenarios:
  - Scenario 1 (Live Deduplication Suggestion): Nguoi dung nhap tieu de gop y, he thong goi y danh sach bai da co san kem so luot vote hien tai; nguoi dung co the chon bo phieu truc tiep cho bai cu thay vi tao bai moi.
  - Scenario 2 (Feedback Submission & Auto-Subscription): Nguoi dung xac nhan y tuong moi, nhap mo ta Markdown, tai tep anh minh hoa; he thong luu Post, luu PostAttachment va tu dong tao PostSubscription.
  - Scenario 3 (Moderated Board Submission): Nguoi dung gui bai tren bang yeu cau kiem duyet; he thong giu bai o trang thai cho duyet (`is_active = false`), Moderator vao hang doi duyet de cong khai hoac tu choi.
- Observable Acceptance Criteria:
  - AC-01: Truy van danh sach Boards va Categories theo Workspace voi thu tu sap xep `displayOrder` va cờ cong khai `isPublic`.
  - AC-02: Endpoint `GET /api/v1/posts/search-similar` tra ve cac bai dang tuong dong tren cung Board dua vao do giong nhau cua tieu de voi thoi gian dap ung duoi 200ms.
  - AC-03: Tao bai dang moi ho tro noi dung Markdown, Category hop le, danh sach Tag da chon, va danh sach tep dinh kem (dung luong toi da 10MB moi tep, dinh dang ho tro: PNG, JPG, WEBP, PDF).
  - AC-04: Tu dong tao ban ghi trong `post_subscriptions` cho tac gia bai viet ngay khi Post duoc tao thanh cong.
  - AC-05: Cac Board co `isModerated = true` se giu bai dang o trang thai cho duyet, khong xuat hien tren feed cong khai cho den khi duoc Moderator phe duyet.

## 2. Domain Entities & Persistence

- Primary Entities:
  - `Board`: Bảng phản hồi chuyên đề (Core Features, Mobile App, Bug Reports, Integrations).
  - `Category`: Danh mục kỹ thuật thuộc Board (UI/UX, Backend, Performance, Security).
  - `Tag`: Nhãn hệ thống linh hoạt.
  - `PostTag`: Liên kết nhiều-nhiều giữa Bài đăng và Nhãn.
  - `Post`: Bài đăng yêu cầu tính năng / báo lỗi.
  - `PostAttachment`: Tệp đính kèm và ảnh chụp màn hình minh họa.
- Related Entities:
  - `Workspace` (so huu Board).
  - `VoterProfile` / `User` (tac gia bai dang).
  - `PostStatus` (trang thai khoi diem cua bai dang).
  - `PostSubscription` (dang ky theo doi tu dong).
- Schema Changes:
  ```prisma
  model Board {

    slug         String

    @@map("post_attachments")
  ```

## 4. API & Data Flow Contracts

### 4.1 Request & Response Contract: Tim Kiem Tuong Dong (Search Similar)

- Endpoint: `GET /api/v1/posts/search-similar?boardId=<boardId>&q=<titleQuery>`
- Authentication: Public
- Request Parameters:
  - `boardId`: UUID cua Board
  - `q`: Chuoi ky tu nguoi dung dang go (do dai toi thieu 3 ky tu)
- Success Response (200 OK):
  ```json
  {
    "success": true,
    "data": [
      {
        "id": "p4018c12-3333-4444-9999-123456789abc",
        "title": "Tich hop Google SSO Login",
        "slug": "tich-hop-google-sso-login",
        "totalVotesCount": 45,
        "totalScoreWeight": 78.50,
        "status": {
          "id": 2,
          "name": "Planned",
          "colorHex": "#3B82F6"
        },
        "similarityScore": 0.86
      }
    ]
  }
  ```

### 4.2 Request & Response Contract: Tao Post Moi

- Endpoint: `POST /api/v1/posts`
- Authentication: Session cua User hoac VoterProfile ID
- Request Payload:
