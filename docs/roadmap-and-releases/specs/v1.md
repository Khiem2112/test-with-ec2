## 1. Overview & Acceptance Criteria

- Objective: Cung cap bang lo trinh Kanban tuong tac keo tha, quan ly cac phien ban phat hanh san pham (ReleaseVersion) va xuat ban trang nhat ky thay doi (Changelog) dinh kem danh sach tinh nang thuc te.
- Target Actors: Public Customer / Voter, Product Manager, Tech Lead.
- Key Scenarios:
  - Scenario 1 (Roadmap Exploration & Filtering): Khach hang xem tien do cac tinh nang tren cac cot trang thai (Under Review, Planned, In Progress, Completed), loc theo Board, Category va Tags.
  - Scenario 2 (Admin Drag-and-Drop Transition): PM keo the tinh nang tu cot Planned sang In Progress tren bang Kanban; he thong tu dong cap nhat statusId va ghi lich su.
  - Scenario 3 (Release Packaging & Changelog Publishing): PM tao ban phat hanh v2.0.0, chon 5 tinh nang da xong gan vao ReleaseItem, soan thao Changelog Markdown va xuat ban; he thong gui thong bao email den toan bo subscriber cua 5 tinh nang.
- Observable Acceptance Criteria:
  - AC-01: Endpoint `GET /api/v1/roadmap` tra ve cau truc cot Kanban theo cac trang thai co `showOnRoadmap = true`, sap xep the theo `totalScoreWeight` giam dan.
  - AC-02: Keo tha the tren Kanban kich hoat cap nhat trang thai bai dang qua `PATCH /api/v1/posts/[id]/status` va luu lich su vao `post_status_histories`.
  - AC-03: Tao va quan ly phien ban phat hanh `ReleaseVersion` voi ten duy nhat trong Workspace (`@@unique([workspaceId, versionName])`), ngay muc tieu (`targetDate`) va ngay phat hanh (`releasedAt`).
  - AC-04: Gan cac bai dang da hoan thanh vao phien ban phat hanh thong qua thuc the trung gian `ReleaseItem`.
  - AC-05: Bien tap va xuat ban `Changelog` voi tieu de, tom tat, than bai Markdown; khi `isPublished = true`, kich hoat gui thong bao toi toan bo nguoi dung da dang ky theo doi cac bai dang lien quan.

## 2. Domain Entities & Persistence

- Primary Entities:
  - `RoadmapView`: Cấu hình các góc nhìn lộ trình công khai/nội bộ.
  - `ReleaseVersion`: Phiên bản phát hành sản phẩm.
  - `ReleaseItem`: Liên kết tính năng thuộc về phiên bản phát hành nào.
  - `Changelog`: Bài viết thông báo cập nhật tính năng mới.
- Related Entities:
  - `Workspace` (sở hữu RoadmapView, ReleaseVersion, Changelog).
  - `Post` (thẻ hiển thị trên lộ trình và gắn vào ReleaseItem).
  - `PostStatus` (định nghĩa các cột trên bảng Kanban).
- Schema Changes:
  ```prisma
  model RoadmapView {
    id           Int         @id @default(autoincrement())
    workspaceId  String      @map("workspace_id")
    name         String
    slug         String
    isDefault    Boolean     @default(false) @map("is_default")
    columnConfig Json        @default("[]") @map("column_config")

    workspace    Workspace   @relation(fields: [workspaceId], references: [id], onDelete: Cascade)

    isActive     Boolean     @default(true) @map("is_active")
    createdAt    DateTime    @default(now()) @map("created_at")
    updatedAt    DateTime    @updatedAt @map("updated_at")

    @@unique([workspaceId, slug])
    @@map("roadmap_views")
  }

  model ReleaseVersion {
    id          String        @id @default(uuid())
    workspaceId String        @map("workspace_id")
    versionName String        @map("version_name")
    targetDate  DateTime?     @map("target_date")
    releasedAt  DateTime?     @map("released_at")
    isPublished Boolean       @default(false) @map("is_published")

    workspace   Workspace     @relation(fields: [workspaceId], references: [id], onDelete: Cascade)
    items       ReleaseItem[]
    changelog   Changelog?

    isActive    Boolean       @default(true) @map("is_active")
    createdAt   DateTime      @default(now()) @map("created_at")
    updatedAt   DateTime      @updatedAt @map("updated_at")

    @@unique([workspaceId, versionName])
    @@map("release_versions")
  }

  model ReleaseItem {
    id               Int            @id @default(autoincrement())
    releaseVersionId String         @map("release_version_id")
    postId           String         @map("post_id")
    completedNote    String?        @map("completed_note")

    releaseVersion   ReleaseVersion @relation(fields: [releaseVersionId], references: [id], onDelete: Cascade)
    post             Post           @relation(fields: [postId], references: [id], onDelete: Cascade)

    createdAt        DateTime       @default(now()) @map("created_at")

    @@unique([releaseVersionId, postId])
    @@map("release_items")
  }

  model Changelog {
    id               String          @id @default(uuid())
    workspaceId      String          @map("workspace_id")
    releaseVersionId String?         @unique @map("release_version_id")
    title            String
    slug             String
    summary          String          @db.Text
    bodyMarkdown     String          @map("body_markdown") @db.Text
    isPublished      Boolean         @default(false) @map("is_published")
    publishedAt      DateTime?       @map("published_at")

    workspace        Workspace       @relation(fields: [workspaceId], references: [id], onDelete: Cascade)
    releaseVersion   ReleaseVersion? @relation(fields: [releaseVersionId], references: [id], onDelete: SetNull)

    isActive         Boolean         @default(true) @map("is_active")
    createdAt        DateTime        @default(now()) @map("created_at")
    updatedAt        DateTime        @updatedAt @map("updated_at")

    @@unique([workspaceId, slug])
    @@map("changelogs")
  }
  ```
- Audit columns: Cac thuc the mutable (`RoadmapView`, `ReleaseVersion`, `Changelog`) deu co bo ba `isActive`, `createdAt`, `updatedAt`.
- Migration & Rollback Strategy: Tao migration bo sung 4 bang; rollback bang migration down.

## 4. API & Data Flow Contracts

### 4.1 Request & Response Contract: Lay Du Lieu Bang Lo Trinh (Roadmap Query)

- Endpoint: `GET /api/v1/roadmap?workspaceId=<workspaceId>`
- Authentication: Public
- Request Parameters:
  - `workspaceId`: UUID cua khong gian lam viec
- Success Response (200 OK):
