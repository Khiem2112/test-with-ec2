## 1. Overview & Acceptance Criteria

- Objective: Cung cap he thong bieu quyet thong minh voi trong so theo cap bac tai khoan (Standard, Pro, Enterprise); chong gian lan spam bot; dong thoi ho tro thao luan da tang dang cay va phan tach ghi chu ky thuat noi bo danh rieng cho doi ngu to chuc.
- Target Actors: Voter (Customer, End User), Internal Team Member (Product Manager, Developer, Moderator, Admin).
- Key Scenarios:
  - Scenario 1 (Smart Upvote / Unvote Toggle): Nguoi dung nhan Upvote, he thong doc `voteWeight` cua VoterProfile (vi du: Enterprise = 5.00), mo transaction tang `totalVotesCount` va `totalScoreWeight`, ghi nhat ky vao `VoteActivityLog`. Nhan lan nua se rut lai phieu bau (Unvote).
  - Scenario 2 (Threaded Nested Discussion): Nguoi dung phan hoi mot binh luan cu the thong qua `parentId`; he thong tra ve cay phan cap thao luan hoan chinh.
  - Scenario 3 (Internal Note Submission & Privacy Guard): Thanh vien to chuc tao ghi chu ky thuat noi bo; he thong dam bao khach hang ben ngoai truy van tuyet doi khong nhin thay du lieu nay nho bo loc `WHERE is_internal_note = false`.
- Observable Acceptance Criteria:
  - AC-01: Endpoint `POST /api/v1/posts/[id]/vote` xu ly toggle vote/unvote nguyen tu trong Database Transaction, cap nhat dong thoi `totalVotesCount` va `totalScoreWeight` theo `appliedWeight`.
  - AC-02: Ghi nhan moi thao tac vote vao `VoteActivityLog` voi IP hash va User Agent; phat hien xung dot dong thoi thong qua rang buoc duy nhat `@@unique([postId, voterProfileId])`.
  - AC-03: Binh luan ho tro phan cap da tang qua `parentId`, cap nhat chi so `commentsCount` tren bang `posts`.
  - AC-04: Ghi chu noi bo (`isInternalNote = true`) chi cho phep thanh vien thuoc `WorkspaceMember` doc va tao; nguoi dung cong khai bi chan hoan toan.
  - AC-05: Tu dong bo sung nguoi vote va nguoi comment vao bang `post_subscriptions` de nhan thong bao cap nhat tien do.

## 2. Domain Entities & Persistence

- Primary Entities:
  - `Vote`: Lượt bình chọn bài đăng kèm trọng số thực tế.
  - `VoteActivityLog`: Nhật ký hành vi bỏ phiếu nhằm kiểm toán chống gian lận.
  - `Comment`: Thảo luận đa tầng và ghi chú kỹ thuật nội bộ.
  - `CommentReaction`: Phản ứng đánh giá trên bình luận.
- Related Entities:
  - `Post` (nhận lượt vote và bình luận).
  - `VoterProfile` (chủ thể bỏ phiếu).
  - `User` (chủ thể bình luận hệ thống).
  - `PostSubscription` (theo dõi tự động).
- Schema Changes:
  - Enums:
    ```prisma
    enum ReactionType {
      THUMBS_UP
      THUMBS_DOWN
      HEART
      ROCKET
      INSIGHTFUL
    }
    ```
  - Models:
    ```prisma
    model Vote {
      id             Int          @id @default(autoincrement())
      postId         String       @map("post_id")
      voterProfileId String       @map("voter_profile_id")
      appliedWeight  Decimal      @default(1.00) @map("applied_weight") @db.Decimal(5, 2)
      ipAddressHash  String?      @map("ip_address_hash")

      post           Post         @relation(fields: [postId], references: [id], onDelete: Cascade)
      voterProfile   VoterProfile @relation(fields: [voterProfileId], references: [id], onDelete: Cascade)

      createdAt      DateTime     @default(now()) @map("created_at")

      @@unique([postId, voterProfileId])
      @@map("votes")
    }

    model VoteActivityLog {
      id             Int          @id @default(autoincrement())
      postId         String       @map("post_id")
      voterProfileId String       @map("voter_profile_id")
      actionType     String       @map("action_type")
      ipAddressHash  String?      @map("ip_address_hash")
      userAgent      String?      @map("user_agent")

      voterProfile   VoterProfile @relation(fields: [voterProfileId], references: [id], onDelete: Cascade)

      createdAt      DateTime     @default(now()) @map("created_at")

      @@map("vote_activity_logs")
    }

    model Comment {
      id             String            @id @default(uuid())
      postId         String            @map("post_id")
      authorUserId   String?           @map("author_user_id")
      parentId       String?           @map("parent_id")
      authorName     String            @map("author_name")
      content        String            @db.Text
      isInternalNote Boolean           @default(false) @map("is_internal_note")
      isPinned       Boolean           @default(false) @map("is_pinned")

      post           Post              @relation(fields: [postId], references: [id], onDelete: Cascade)
      authorUser     User?             @relation(fields: [authorUserId], references: [id], onDelete: SetNull)
      parentComment  Comment?          @relation("NestedReplies", fields: [parentId], references: [id], onDelete: Cascade)
      replies        Comment[]         @relation("NestedReplies")
      reactions      CommentReaction[]

      isActive       Boolean           @default(true) @map("is_active")
      createdAt      DateTime          @default(now()) @map("created_at")
      updatedAt      DateTime          @updatedAt @map("updated_at")

      @@map("comments")
    }

    model CommentReaction {
      id        Int          @id @default(autoincrement())
      commentId String       @map("comment_id")
      userId    String?      @map("user_id")
      voterId   String?      @map("voter_id")
      type      ReactionType

      comment   Comment      @relation(fields: [commentId], references: [id], onDelete: Cascade)

      createdAt DateTime     @default(now()) @map("created_at")

      @@unique([commentId, userId, type])
      @@map("comment_reactions")
    }
    ```
  - Audit columns: Bang `Comment` chua `isActive`, `createdAt`, `updatedAt`.
  - Migration & Rollback Strategy: Ap dung migration cho bang Vote va Comment; rollback thong qua migration down.

## 4. API & Data Flow Contracts

### 4.1 Request & Response Contract: Toggle Vote

- Endpoint: `POST /api/v1/posts/[id]/vote`
- Authentication: VoterProfile ID hoac Session
- Request Payload:
  ```json
  {
    "voterProfileId": "v9821a00-1111-4444-8888-abcdef123456"
  }
  ```
- Success Response (200 OK):
  ```json
  {
    "success": true,
    "data": {
      "action": "UPVOTED",
      "postId": "p5555555-6666-7777-8888-999999999999",
      "totalVotesCount": 46,
      "totalScoreWeight": 83.50,
      "userHasVoted": true
    }
  }
  ```
- Error Responses (400 / 404 / 409 / 500):
  ```json
  {
    "success": false,
    "error": {
      "code": "POST_LOCKED",
      "message": "Bai viet nay da bi dong bang thao luan va binh chon boi ban quan tri"
    }
  }
  ```

### 4.2 Request & Response Contract: Tao Comment / Ghi Chu Noi Bo

- Endpoint: `POST /api/v1/posts/[id]/comments`
- Authentication: Session cua User hoac VoterProfile ID
- Request Payload:
  ```json
  {
    "authorName": "Doan Cong Hau",
    "content": "Module nay can tich hop san hop thoai xuat file de nguoi dung tien thao tac.",
    "parentId": null,
    "isInternalNote": false
  }
  ```
- Success Response (201 Created):
  ```json
  {
    "success": true,
    "data": {
      "id": "c7777777-8888-9999-aaaa-bbbbbbbbbbbb",
      "postId": "p5555555-6666-7777-8888-999999999999",
      "authorName": "Doan Cong Hau",
      "content": "Module nay can tich hop san hop thoai xuat file de nguoi dung tien thao tac.",
      "isInternalNote": false,
      "createdAt": "2026-11-06T00:00:00.000Z"
    }
  }
  ```
