## 1. Overview & Acceptance Criteria

- Objective: Cung cap he thong quan ly chu trinh song tinh nang tu luc tiep nhan den khi xuat ban; dong thoi trang bi dong co gop bai nguyen tu (Post Merge Engine) giup hop nhat cac bai dang trung lap, bao toan tuyet doi so phieu bau va nguoi theo doi.
- Target Actors: Product Manager, Workspace Administrator, Moderator.
- Key Scenarios:
  - Scenario 1 (Status Transition): Product Manager chuyen trang thai bai viet tu Planned sang In Progress, nhap ghi chu ly do (Change Note); he thong luu lich su vao `post_status_histories` va phat thong bao den toan bo subscriber.
  - Scenario 2 (Merge Preview): PM phat hien bai B trung lap voi bai A, mo drawer gop bai; he thong tinh toan truoc so vote hop le se chuyen, so vote trung lap se bo qua va so subscriber se di doi.
  - Scenario 3 (Atomic Merge Execution): PM xac nhan gop bai; he thong chay giao dich nguyen tu chuyen vote, cap nhat tong diem bai A, chuyen subscriber, khoa bai B va gan `mergedIntoPostId = A.id`.
- Observable Acceptance Criteria:
  - AC-01: Quan ly danh muc trang thai tuy bien (Custom Post Statuses) voi cac nhom tieu chuan: BACKLOG, UNSCHEDULED, PLANNED, IN_PROGRESS, COMPLETED, CLOSED, DECLINED.
  - AC-02: Endpoint `PATCH /api/v1/posts/[id]/status` cap nhat trang thai bai viet, ghi nhat ky vao `post_status_histories` va `audit_logs` trong cung mot giao dich.
  - AC-03: Endpoint `POST /api/v1/posts/[id]/merge-preview` tinh toan truoc so vote thuc chuyen (loai bo trung lap boi VoterProfile), tong diem trong so tang them va so nguoi theo doi duoc chuyen giao.
  - AC-04: Endpoint `POST /api/v1/posts/[id]/merge` thuc thi dong co gop bai nguyen tu: chuyen vote khong trung, recalculate `totalVotesCount` va `totalScoreWeight` cua bai dich, chuyen nguoi theo doi, khoa bai nguon voi `mergedIntoPostId`, va tao ban ghi trong `post_merge_histories`.
  - AC-05: Kiem tra va chan tuyet doi cac truong hop: gop bai vao chinh no, chu trinh gop vong tron, hoac gop vao mot bai da bi hop nhat truoc do.

## 2. Domain Entities & Persistence

- Primary Entities:
  - `PostStatus`: Danh mục trạng thái tùy biến cho vòng đời tính năng.
  - `PostStatusHistory`: Sổ nhật ký ghi vết chuyển trạng thái bài đăng.
  - `PostMergeHistory`: Lưu vết lịch sử gộp bài trùng lặp.
  - `Post`: Bài đăng yêu cầu tính năng / báo lỗi.
- Related Entities:
  - `Workspace` (sở hữu PostStatus).
  - `Vote` (đối tượng chuyển nhượng khi gộp bài).
  - `PostSubscription` (đối tượng di dời khi gộp bài).
  - `AuditLog` (lưu vết thao tác quản trị).
- Schema Changes:
  - Enums:
    ```prisma
    enum StatusCategory {
      BACKLOG
      UNSCHEDULED
      PLANNED
      IN_PROGRESS
      COMPLETED
      CLOSED
      DECLINED
    }
    ```
  - Models:
    ```prisma
    model PostStatus {
      id            Int                 @id @default(autoincrement())
      workspaceId   String              @map("workspace_id")
      name          String
      key           String
      category      StatusCategory      @default(BACKLOG)
      colorHex      String              @default("#3B82F6") @map("color_hex")
      showOnRoadmap Boolean             @default(false) @map("show_on_roadmap")
      displayOrder  Int                 @default(0) @map("display_order")

      workspace     Workspace           @relation(fields: [workspaceId], references: [id], onDelete: Cascade)
      posts         Post[]
      sourceHistory PostStatusHistory[] @relation("OldStatusRelation")
      targetHistory PostStatusHistory[] @relation("NewStatusRelation")

      isActive      Boolean             @default(true) @map("is_active")
      createdAt     DateTime            @default(now()) @map("created_at")
      updatedAt     DateTime            @updatedAt @map("updated_at")

      @@unique([workspaceId, key])
      @@map("post_statuses")
    }

    model PostStatusHistory {
      id          Int         @id @default(autoincrement())
      postId      String      @map("post_id")
      oldStatusId Int?        @map("old_status_id")
      newStatusId Int         @map("new_status_id")
      changedById String?     @map("changed_by_id")
      changeNote  String?     @map("change_note") @db.Text

      post        Post        @relation(fields: [postId], references: [id], onDelete: Cascade)
      oldStatus   PostStatus? @relation("OldStatusRelation", fields: [oldStatusId], references: [id], onDelete: SetNull)
      newStatus   PostStatus  @relation("NewStatusRelation", fields: [newStatusId], references: [id], onDelete: Restrict)
      changedBy   User?       @relation("StatusUpdatedByUser", fields: [changedById], references: [id], onDelete: SetNull)

      createdAt   DateTime    @default(now()) @map("created_at")

      @@map("post_status_histories")
    }

    model PostMergeHistory {
      id               Int      @id @default(autoincrement())
      sourcePostId     String   @map("source_post_id")
      targetPostId     String   @map("target_post_id")
      performedById    String?  @map("performed_by_id")
      votesTransferred Int      @default(0) @map("votes_transferred")

      sourcePost       Post     @relation("SourcePostMerges", fields: [sourcePostId], references: [id], onDelete: Cascade)
      targetPost       Post     @relation("TargetPostMerges", fields: [targetPostId], references: [id], onDelete: Cascade)

      createdAt        DateTime @default(now()) @map("created_at")

      @@map("post_merge_histories")
    }
    ```
  - Model Post Update:
    - Bổ sung `mergedIntoPostId String? @map("merged_into_post_id")`.
    - Quan hệ `mergedTarget Post?` và `mergedSources Post[]`.
  - Audit columns: Bang `PostStatus` chua `isActive`, `createdAt`, `updatedAt`.
  - Migration & Rollback Strategy: Them cac cot va bang lich su; rollback bang migration down.

## 4. API & Data Flow Contracts

### 4.1 Request & Response Contract: Chuyen Doi Trang Thai

- Endpoint: `PATCH /api/v1/posts/[id]/status`
- Authentication: Session (Role: Admin hoac Product Manager)
- Request Payload:
  ```json
  {
    "newStatusId": 3,
    "changeNote": "Doi ngu Frontend da bat dau trien khai giao dien bo loc trong Sprint 14.",
    "notifySubscribers": true
  }
  ```
- Success Response (200 OK):
  ```json
  {
    "success": true,
    "data": {
      "postId": "p5555555-6666-7777-8888-999999999999",
      "oldStatusId": 2,
      "newStatusId": 3,
      "updatedAt": "2026-11-06T00:00:00.000Z",
      "historyId": 14
    }
  }
  ```

### 4.2 Request & Response Contract: Thuc Thi Gop Bai (Post Merge)

- Endpoint: `POST /api/v1/posts/[id]/merge`
- Authentication: Session (Role: Admin hoac Product Manager)
- Request Payload:
  ```json
  {
    "targetPostId": "p4018c12-3333-4444-9999-123456789abc"
  }
  ```
- Success Response (200 OK):
  ```json
  {
    "success": true,
    "data": {
      "sourcePostId": "p5555555-6666-7777-8888-999999999999",
      "targetPostId": "p4018c12-3333-4444-9999-123456789abc",
      "votesTransferred": 9,
      "subscribersTransferred": 8,
      "targetNewTotalVotes": 54,
      "targetNewScoreWeight": 92.50,
      "mergedAt": "2026-11-06T00:00:00.000Z"
    }
  }
  ```
- Error Responses (400 / 404 / 409 / 500):
  ```json
  {
    "success": false,
    "error": {
      "code": "CIRCULAR_MERGE_DETECTED",
      "message": "Khong the gop bai viet vao chinh no hoac tao chu trinh gop bai vong tron"
    }
  }
  ```
