## 1. Overview & Acceptance Criteria

- Objective: Thiet lap he thong dong bo thong tin da chieu qua hop thu thong bao trong ung dung va email; phat su kien Webhook hai chieu tich hop den cac ung dung ngoai (Slack, Discord, Jira); dong thoi luu tru nhat ky kiem toan quan tri bat bien nham dam bao tinh minh bach.
- Target Actors: End User (Voter/Subscriber), Product Manager, System Administrator, External Webhook Consumers.
- Key Scenarios:
  - Scenario 1 (Auto-Subscription & Status Notification): Nguoi dung bo phieu cho mot tinh nang; he thong tu dong tao ban ghi trong `post_subscriptions`. Khi tinh nang duoc chuyen sang Completed, he thong day thong bao in-app va email den nguoi dung.
  - Scenario 2 (HMAC Signed Webhook Dispatch): Admin dang ky Webhook cho su kien `POST_CREATED`; khi co bai moi, hang doi dong goi JSON payload, tao tieu de `X-RoadmapHub-Signature` bang HMAC SHA-256 va phat den Slack endpoint. Neu endpoint loi, he thong tu dong thu lai voi co che Exponential Backoff.
  - Scenario 3 (Audit Log Inspection): Quan tri vien truy cap so kiem toan de tra cuu xem ai da thay doi trang thai tinh nang hoac thuc hien gop bai, xem dia chi IP va diff JSON chi tiet.
- Observable Acceptance Criteria:
  - AC-01: Co che tu dong theo doi tao ban ghi `PostSubscription` cho nguoi tao bai, nguoi vote, va nguoi comment; ho tro nguoi dung bat tat rieng biet `notifyEmail` va `notifyInApp`.
  - AC-02: Endpoint `GET /api/v1/notifications` tra ve danh sach thong bao cua nguoi dung kem so luong tin chua doc; endpoint `PATCH /api/v1/notifications/[id]/read` cap nhat `isRead = true`.
  - AC-03: Dang ky Webhook qua `POST /api/v1/webhooks` tu dong sinh chuoi `secretKey` ngau nhien 32 ky tu va rang buoc danh sach su kien duoc phep lang nghe.
  - AC-04: Tac vu phat Webhook tao chu ky HMAC SHA-256 qua tieu de `X-RoadmapHub-Signature: sha256=<hex>` va ap dung co che retry toi da 5 lan (1m, 5m, 15m, 1h).
  - AC-05: Ghi nhat ky bat bien vao bang `audit_logs` cho moi thao tac nhay cam (doi quyen thanh vien, xoa phan hoi, gop bai, doi trang thai lo trinh) kem dia chi IP va JSON details.

## 2. Domain Entities & Persistence

- Primary Entities:
  - `PostSubscription`: Danh sách người theo dõi để gửi thông báo tiến độ.
  - `Notification`: Hộp thư thông báo trong ứng dụng cho người dùng.
  - `WebhookSubscription`: Cấu hình webhook phát sự kiện ra hệ thống ngoài.
  - `AuditLog`: Sổ kiểm toán ghi lại thao tác nhạy cảm của quản trị viên.
- Related Entities:
  - `Post` (chủ đề đăng ký theo dõi).
  - `User` (người nhận thông báo và tác nhân trong AuditLog).
  - `Workspace` (phạm vi Webhook và AuditLog).
- Schema Changes:
  - Enums:
    ```prisma
    enum NotificationType {
      STATUS_CHANGED
      NEW_COMMENT
      OFFICIAL_RESPONSE
      FEATURE_RELEASED
      MENTIONED
    }

    enum WebhookEvent {
      POST_CREATED
      POST_STATUS_CHANGED
      POST_MERGED
      COMMENT_ADDED
      RELEASE_PUBLISHED
    }
    ```
  - Models:
    ```prisma
    model PostSubscription {
      id             Int          @id @default(autoincrement())
      postId         String       @map("post_id")
      voterProfileId String       @map("voter_profile_id")
      notifyEmail    Boolean      @default(true) @map("notify_email")
      notifyInApp    Boolean      @default(true) @map("notify_in_app")

      post           Post         @relation(fields: [postId], references: [id], onDelete: Cascade)
      voterProfile   VoterProfile @relation(fields: [voterProfileId], references: [id], onDelete: Cascade)

      createdAt      DateTime     @default(now()) @map("created_at")

      @@unique([postId, voterProfileId])
      @@map("post_subscriptions")
    }

    model Notification {
      id        String           @id @default(uuid())
      userId    String           @map("user_id")
      type      NotificationType
      title     String
      message   String           @db.Text
      actionUrl String?          @map("action_url")
      isRead    Boolean          @default(false) @map("is_read")

      user      User             @relation(fields: [userId], references: [id], onDelete: Cascade)

      createdAt DateTime         @default(now()) @map("created_at")

      @@index([userId, isRead])
      @@map("notifications")
    }

    model WebhookSubscription {
      id          String         @id @default(uuid())
      workspaceId String         @map("workspace_id")
      targetUrl   String         @map("target_url")
      secretKey   String         @map("secret_key")
      events      WebhookEvent[]

      workspace   Workspace      @relation(fields: [workspaceId], references: [id], onDelete: Cascade)

      isActive    Boolean        @default(true) @map("is_active")
      createdAt   DateTime       @default(now()) @map("created_at")
      updatedAt   DateTime       @updatedAt @map("updated_at")

      @@map("webhook_subscriptions")
    }

    model AuditLog {
      id          Int       @id @default(autoincrement())
      workspaceId String    @map("workspace_id")
      userId      String?   @map("user_id")
      action      String
      entityType  String    @map("entity_type")
      entityId    String    @map("entity_id")
      details     Json      @default("{}")
      ipAddress   String?   @map("ip_address")

      workspace   Workspace @relation(fields: [workspaceId], references: [id], onDelete: Cascade)
      user        User?     @relation(fields: [userId], references: [id], onDelete: SetNull)

      createdAt   DateTime  @default(now()) @map("created_at")

      @@index([workspaceId, entityType, entityId])
      @@map("audit_logs")
    }
    ```
  - Audit columns: Bang `WebhookSubscription` chua `isActive`, `createdAt`, `updatedAt`; `AuditLog` la bang append-only bat bien chua `createdAt`.
  - Migration & Rollback Strategy: Tao migration bo sung 4 bang; rollback bang migration down.

## 4. API & Data Flow Contracts

### 4.1 Request & Response Contract: Tra Cuu Hop Thu Thong Bao

- Endpoint: `GET /api/v1/notifications`
- Authentication: Session cua User
- Request Parameters: `page=1&limit=20&unreadOnly=false`
- Success Response (200 OK):
  ```json
  {
    "success": true,
    "data": {
      "unreadCount": 3,
      "notifications": [
        {
          "id": "n1111111-2222-3333-4444-555555555555",
          "type": "STATUS_CHANGED",
          "title": "Tinh nang ban quan tam da hoan thanh",
          "message": "Tinh nang 'Ho tro Dark Mode tren Mobile' da duoc chuyen sang trang thai Completed.",
          "actionUrl": "/autoflow/posts/ho-tro-dark-mode-tren-mobile",
          "isRead": false,
          "createdAt": "2026-11-06T00:00:00.000Z"
        }
      ]
    }
  }
  ```

### 4.2 Request & Response Contract: Dang Ky Webhook

- Endpoint: `POST /api/v1/webhooks`
- Authentication: Session (Role: Owner hoac Admin)
- Request Payload:
  ```json
  {
    "workspaceId": "c1f7b0a8-2026-4b68-b765-a87612345678",
    "targetUrl": "https://hooks.slack.com/services/T00/B00/XXXXX",
    "events": ["POST_CREATED", "POST_STATUS_CHANGED", "RELEASE_PUBLISHED"]
  }
  ```
- Success Response (201 Created):
  ```json
  {
    "success": true,
    "data": {
      "id": "w8888888-9999-0000-aaaa-bbbbbbbbbbbb",
      "workspaceId": "c1f7b0a8-2026-4b68-b765-a87612345678",
      "targetUrl": "https://hooks.slack.com/services/T00/B00/XXXXX",
      "secretKey": "sec_9f83ab27e8d91029c7b6a5d4e3f21098",
      "events": ["POST_CREATED", "POST_STATUS_CHANGED", "RELEASE_PUBLISHED"],
      "isActive": true,
      "createdAt": "2026-11-06T00:00:00.000Z"
    }
  }
  ```
