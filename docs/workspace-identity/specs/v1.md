## 1. Overview & Acceptance Criteria

- Objective: Thiet lap nen tang quan tri da khong gian lam viec (Multi-tenant Workspace), co che phan quyen vai tro noi bo (RBAC), quan ly phien lam viec bao mat va he thong dinh danh VoterProfile dong nhat cho nguoi dung cuoi.
- Target Actors: Workspace Owner, Workspace Administrator, Internal Team Member (Product Manager, Developer, Moderator), End Voter (Customer, Anonymous Guest).
- Key Scenarios:
  - Scenario 1 (Workspace Onboarding): Owner dang ky to chuc moi, he thong kiem tra tinh duy nhat cua slug, tao Workspace va tu dong gan vai tro OWNER trong WorkspaceMember.
  - Scenario 2 (Team Invitation & RBAC): Admin moi nhan su vao to chuc qua email, chi dinh vai tro (Product Manager, Developer, Moderator); he thong chan Developer truy cap cac route quan tri he thong nhay cam voi ma loi HTTP 403 Forbidden.
  - Scenario 3 (Voter Profile Resolution): Khach hang truy cap cong gop y, he thong nhan dien dinh danh qua tai khoan he thong, xac thuc JWT SSO tu ung dung doi tac, hoac tao ma bam van tay thiet bi ket hop dia chi IP salt cho nguoi dung an danh.
- Observable Acceptance Criteria:
  - AC-01: Tao khong gian lam viec voi slug duy nhat tren he thong; tu dong tao ban ghi `WorkspaceMember` cho nguoi tao voi vai tro `OWNER`.
  - AC-02: Ho tro cap nhat cau hinh nhan dien thuong hieu (`brandingConfig` dang JSON) va ten mien tuy chinh (`customDomain`).
  - AC-03: Phan quyen RBAC nghiem ngat qua Middleware va Server Action guard; chan toan bo truy cap trai phep giua cac khong gian lam viec khac nhau.
  - AC-04: Dinh danh nguoi dung cuoi (VoterProfile Resolution) tra ve ban ghi duy nhat theo `(workspaceId, externalUserId)` hoac `(workspaceId, fingerprintHash)`.
  - AC-05: Khoi tao phien lam viec `UserSession` voi ma bam token duy nhat (`tokenHash`) va co che tu dong het han theo thoi gian (`expiresAt`).

## 2. Domain Entities & Persistence

- Primary Entities:
  - `Workspace`: Thuc the khong gian lam viec to chuc/san pham.
  - `User`: Tai khoan nguoi dung he thong.
  - `WorkspaceMember`: Thanh vien noi bo va phan quyen vai tro trong Workspace.
  - `UserSession`: Phien lam viec cua nguoi dung he thong.
  - `VoterProfile`: Ho so dinh danh nguoi bo phieu (Registered, SSO, Anonymous).
- Related Entities:
  - `Board`, `PostStatus`, `RoadmapView`, `ReleaseVersion`, `Changelog`, `WebhookSubscription`, `AuditLog` (thuoc Workspace).
  - `Vote`, `VoteActivityLog`, `PostSubscription` (thuoc VoterProfile).
- Schema Changes:
  - Enums:
    ```prisma
    enum WorkspaceRole {
      OWNER
      ADMIN
      PRODUCT_MANAGER
      DEVELOPER
      MODERATOR
    }

    enum VoterAuthType {
      REGISTERED
      SSO_IDENTIFIED
      ANONYMOUS_FINGERPRINT
    }
    ```
  - Models:
    ```prisma
    model Workspace {
      id             String            @id @default(uuid())
      name           String
      slug           String            @unique
      customDomain   String?           @unique @map("custom_domain")
      brandingConfig Json              @default("{}") @map("branding_config")
      isPublicPortal Boolean           @default(true) @map("is_public_portal")
      members        WorkspaceMember[]
      voterProfiles  VoterProfile[]

      isActive       Boolean           @default(true) @map("is_active")
      createdAt      DateTime          @default(now()) @map("created_at")
      updatedAt      DateTime          @updatedAt @map("updated_at")

      @@map("workspaces")
    }

    model User {
      id           String            @id @default(uuid())
      email        String            @unique
      fullName     String            @map("full_name")
      avatarUrl    String?           @map("avatar_url")
      passwordHash String?           @map("password_hash")
      memberships  WorkspaceMember[]
      sessions     UserSession[]

      isActive     Boolean           @default(true) @map("is_active")
      createdAt    DateTime          @default(now()) @map("created_at")
      updatedAt    DateTime          @updatedAt @map("updated_at")

      @@map("users")
    }

    model WorkspaceMember {
      id          Int           @id @default(autoincrement())
      workspaceId String        @map("workspace_id")
      userId      String        @map("user_id")
      role        WorkspaceRole @default(DEVELOPER)

      workspace   Workspace     @relation(fields: [workspaceId], references: [id], onDelete: Cascade)
      user        User          @relation(fields: [userId], references: [id], onDelete: Cascade)

      isActive    Boolean       @default(true) @map("is_active")
      createdAt   DateTime      @default(now()) @map("created_at")
      updatedAt   DateTime      @updatedAt @map("updated_at")

      @@unique([workspaceId, userId])
      @@map("workspace_members")
    }

    model UserSession {
      id        String   @id @default(uuid())
      userId    String   @map("user_id")
      tokenHash String   @unique @map("token_hash")
      ipAddress String?  @map("ip_address")
      userAgent String?  @map("user_agent")
      expiresAt DateTime @map("expires_at")

      user      User     @relation(fields: [userId], references: [id], onDelete: Cascade)

      createdAt DateTime @default(now()) @map("created_at")

      @@map("user_sessions")
    }

    model VoterProfile {
      id              String            @id @default(uuid())
      workspaceId     String            @map("workspace_id")
      authType        VoterAuthType     @default(REGISTERED) @map("auth_type")
      externalUserId  String?           @map("external_user_id")
      displayName     String            @map("display_name")
      email           String?
      fingerprintHash String?           @map("fingerprint_hash")
      customerTier    String            @default("standard") @map("customer_tier")
      voteWeight      Decimal           @default(1.00) @map("vote_weight") @db.Decimal(5, 2)

      workspace       Workspace         @relation(fields: [workspaceId], references: [id], onDelete: Cascade)

      isActive        Boolean           @default(true) @map("is_active")
      createdAt       DateTime          @default(now()) @map("created_at")
      updatedAt       DateTime          @updatedAt @map("updated_at")

      @@unique([workspaceId, externalUserId])
      @@index([workspaceId, fingerprintHash])
      @@map("voter_profiles")
    }
    ```
  - Audit columns: Moi bang mutable deu co `isActive`, `createdAt`, `updatedAt`.
  - Migration & Rollback Strategy: Ap dung Prisma migration cho SQLite (local mock) va PostgreSQL (production); rollback bang script xoa bang hoac hoan tac migration truoc do.

## 4. API & Data Flow Contracts

### 4.1 Request & Response Contract: Tao Workspace Moi

- Endpoint: `POST /api/v1/workspaces`
- Authentication: Session cua User he thong
- Request Payload:
  ```json
  {
    "name": "AutoFlow Product Hub",
    "slug": "autoflow-product-hub",
    "customDomain": "feedback.autoflow.io",
    "brandingConfig": {
      "primaryColor": "#10B981",
      "logoUrl": "https://cdn.autoflow.io/logo.svg"
    },
    "isPublicPortal": true
  }
  ```
- Success Response (201 Created):
  ```json
  {
    "success": true,
    "data": {
      "id": "c1f7b0a8-2026-4b68-b765-a87612345678",
      "name": "AutoFlow Product Hub",
      "slug": "autoflow-product-hub",
      "customDomain": "feedback.autoflow.io",
      "brandingConfig": {
        "primaryColor": "#10B981",
        "logoUrl": "https://cdn.autoflow.io/logo.svg"
      },
      "isPublicPortal": true,
      "createdAt": "2026-11-06T00:00:00.000Z"
    }
  }
  ```
- Error Responses (400 / 409 / 500):
  ```json
  {
    "success": false,
    "error": {
      "code": "SLUG_ALREADY_EXISTS",
      "message": "Duong dan dinh danh da duoc su dung, vui long chon ten khac"
    }
  }
  ```

### 4.2 Request & Response Contract: Phan Giai Voter Profile

- Endpoint: `POST /api/v1/voter-profiles/resolve`
- Authentication: Public / SSO Bearer Token (tuy chon)
- Request Payload:
  ```json
  {
    "workspaceId": "c1f7b0a8-2026-4b68-b765-a87612345678",
    "authType": "ANONYMOUS_FINGERPRINT",
    "displayName": "Khach An Danh",
    "fingerprintHash": "e3b0c44298fc1c149afbf4c8996fb92427ae41e4649b934ca495991b7852b855"
  }
  ```
- Success Response (200 OK):
  ```json
  {
    "success": true,
    "data": {
      "id": "v9821a00-1111-4444-8888-abcdef123456",
      "workspaceId": "c1f7b0a8-2026-4b68-b765-a87612345678",
      "authType": "ANONYMOUS_FINGERPRINT",
      "displayName": "Khach An Danh",
      "customerTier": "standard",

  ```
