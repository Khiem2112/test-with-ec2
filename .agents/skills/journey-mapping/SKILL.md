# Journey Mapping & Friction Analysis

This skill guides mapping user experience touchpoints and analyzing system friction.

## Core Activities

1. Touchpoint Inventory:
   - Identify every screen, notification, modal, and email the user encounters.
   - Trace chronological progression through onboarding, daily usage, and edge recovery.

2. Friction Detection:
   - Flag redundant data entry steps.
   - Identify confusing status labels or dead-end error pages.
   - Measure cognitive load during multi-step setup workflows.
