# Information Architecture

This skill governs the systematic organization of content, screens, routes, and navigation hierarchies.

## Core Rules

1. Clear Hierarchy:
   - Organize routes and surfaces logically from broad hubs to deep detailed views.
   - Maintain breadcrumb trails reflecting semantic structure rather than historical click paths.

2. Consistent Labeling:
   - Use plain, unambiguous industry terms for navigation labels.
   - Avoid internal jargon or technical implementation names on user-facing navigation.

3. URL Design:
   - Use kebab-case for resource identifiers and routes (`/orders/batch-summary`).
   - Query parameters should be reserved for filtering, sorting, and pagination.
