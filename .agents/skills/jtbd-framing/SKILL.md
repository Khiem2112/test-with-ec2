# Jobs-to-be-Done (JTBD) Framework

This skill applies the Jobs-to-be-Done methodology to ground product features in real user motivations and struggling moments.

## Framing Structure

1. The Struggling Moment:
   - When does the user experience frustration with existing workarounds?
   - What triggers the demand for a new tool or feature?

2. Job Statement Template:
   - When `<situation / trigger>`, I want to `<action / capability>`, so I can `<desired outcome / benefit>`.

3. Hire & Fire Criteria:
   - Hire criteria: What must this feature do exceptionally well to be chosen?
   - Fire criteria: What unacceptable friction would cause the user to abandon this workflow?
